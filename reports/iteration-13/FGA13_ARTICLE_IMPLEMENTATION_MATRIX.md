# FGA-13 article ↔ implementation matrix

| Article promise | Implementation | Verification |
|---|---|---|
| Difficulty is not a row count. | `DifficultyProfile` stores separate ambiguity, noise, graph depth, evidence quality and resource-pressure dimensions; no aggregate difficulty score is used. | `validate_catalogue()` checks vector variance; profile/schema tests reject invalid shapes. |
| Mixed roles and legitimate comparators matter. | `mixed_roles` and `legitimate_comparators` are required profile fields; every canonical package must declare at least one comparator. | `test_thirteen_packages_have_one_non_cumulative_difficulty_profile`; schema mutation test sets the comparator count to zero and is rejected. |
| Academy, Puppy, Adult and Senior are distinct paths. | `PATH_COUNTS`, generated manifests and the memory catalogue publish three Academy, three Puppy, four Adult and three Senior canonical cases; all paths are open. | Catalogue validation and cross-path API regression; fourteen manifests are discovered including the empty Academy shell. |
| Four paths use one shared engine. | `build_web_container()` resolves the active package for rounds, workspace and graph projection; no path-specific engine is introduced. | `test_one_shared_round_engine_serves_each_path` creates, starts, opens and loads a round for all four paths. |
| Difficulty is per package, not cumulative progression. | `progression_mode=PACKAGE_SINGLE_PROFILE` is required by the JSON Schema and `validate_profile()`. | Schema/profile tests reject `CUMULATIVE_LEVEL`. |
| Existing FGA-12 case identity and economy contracts stay stable. | The manifest generator preserves legacy case, economy and scoring versions for ACADEMY_T02 and ACADEMY_T03 while adding the FGA-13 profile. | `tests/iteration_12/test_case_packages.py`, package validation and full repository regression. |
| Learning-sized initial graph views are bounded and honest. | `graph_node_limit` is applied in the application provider; `initial_subset()` preserves snapshot identity and emits `partial`, `omitted_node_count` and `omitted_edge_count`; the API remains capped at 300/700. | Historical graph API tests plus the FGA-13 cross-path test; the first oversized projection failure led to the bound fix. |
| The public graph never receives evaluator truth. | The package graph reads published records/relationships; the existing safe projection guard remains in the shared graph service. | Cross-path workspace payloads are searched for `expected_truth`; Databricks report has no forbidden player columns and does not query truth. |
| The article records actual implementation failures. | `FGA13_IMPLEMENTATION_LOG.md` records catalogue assumptions, oversized projections, dict/dataclass mapping, snapshot compatibility, OpenAPI drift and direct-script import failure. | Each entry names the failing check, correction and result; the log distinguishes the superseded pre-commit Databricks report from the final one. |
| Databricks tests use profile `fga`. | `scripts/qualify_fga13_difficulty.py` calls the live warehouse with the requested profile and only allowlisted read queries. | Final report `databricks-fga13-difficulty-current.json`: `status=pass`, profile `fga`, read-only, thirteen canonical package boundaries, `actual_engine_run=false`. |
| Article images follow the established numbered pair. | `angelic-assets` branch `FGA-13` contains `images/articles/fga/13-puppy-love-adult-problems/1.png` and `2.png`. | Asset commit `31620dfdbc18f59a30390415bd4d3ff3bb899aeb`; article frontmatter and final image use the pinned CDN URLs. |
| The article does not overclaim balance. | The article explicitly calls the cross-path API gate executable playability evidence, not a human usability study; no telemetry or human response is presented as observed fact. | Editorial review against the implementation and report; known limit retained in both article and log. |
