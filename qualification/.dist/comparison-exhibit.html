Qualification protocol and interpretation

Each candidate receives the same fixture and the same sequence: mount, fit, set viewport, resize, probe a node, probe an edge and destroy. The candidate adapter is the only place allowed to hold native library objects. A production decision still requires hard-requirement, licence, accessibility and React-integration evidence.

Manual review: click a node and an edge in every card; use fit, zoom/pan and remount; inspect labels, direction and semantic affordances; then mark the five review items honestly for that candidate.
