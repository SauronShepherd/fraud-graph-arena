# Canonical Model v1

Canonical Model v1.0.0 contains exactly 32 ordered CSV paths. The typed schema registry defines every column, SQL type, and nullability rule; the physical registry defines the governed persistence target. Package-local schema copies are receipts, never independent shape authorities.

The `truth/` layer is protected evaluator material. `published/` and `genie/` are safe projections with separate validation and leakage scanning.
